2. Key Technical Concepts:
   - wakil's two-step ingest pipeline: `wakil ingest {transcript,text,article}` (deterministic capture, now with one small title/abstract model call per ADR 0010) → `wakil enrich <source-id>` (extraction + entity-resolution DAG, preview/confirm/apply).
   - Skill-based judgment system: `src/wakil/skills/<name>/SKILL.md` (+ optional `eval.json`, `references/*.md`), resolved via `wakil.skills.resolver` with kb-local/user/built-in precedence (first-match-wins, per ADR 0001).
   - `BASE_SYSTEM` (`src/wakil/llm/skill_loader.py`) is prepended to every skill's system prompt in both the real pipeline (`build_system_prompt`) and the eval harness (`run_scenario`) — a key lever for universal instructions.
   - Live-model eval suite (`tests/evals/`): `run_scenario` (generation) + `grade_transcript` (grading), gated behind pytest marker `eval`, excluded from required CI per ADR 0004, run via `uv run pytest -m eval ...`.
   - `--context`/`--context-file` feature (`src/wakil/app/context_references.py`): `@file:path[#Heading|:start-end]`, `@url:`, bare-`@` heuristics, token budget (soft 25%/hard 50% of `MODEL_CONTEXT_WINDOW_TOKENS = 180_000`), workspace-root sandboxing, `ResolvedContext`/`_ExpandedPiece` dataclasses (`text`, `digest`, `referenced_paths`).
   - git-native change tracking (`src/wakil/app/git_service.py`, ADR 0003): `commit_message(kind, description) -> f"wakil {kind}: {description}"`, `COMMIT_PREFIXES = ("ingest", "note", "link", "memory", "dream", "source", "chore")`, branch/commit/PR landing via `prepare_landing`/`land_ingestion`, `--local` opt-out.
